# 🎓 SICAD — Sistem Informasi Akademik Digital
📌 Deskripsi Umum

**SICAD adalah aplikasi Sistem Informasi Akademik Digital berbasis web yang digunakan untuk membantu pengelolaan data akademik antara mahasiswa dan dosen secara terpusat, cepat, dan efisien.**

# ⚙️ Spesifikasi Sistem

🌐 Platform: Aplikasi Web

🧠 Backend: Node.js (JavaScript)

🗄️ Database: PostgreSQL

🎨 Frontend: HTML, CSS, JavaScript

🔐 Autentikasi: Login berbasis peran (Role-based Access)

👥 Pengguna: Mahasiswa & Dosen
